# 常见 Bug 模式

形成假设之前要扫描的常见 bug 模式清单。按频率排序。首先检查这些——覆盖所有技术栈约 80% 的 bug。

<patterns>

## 空/未定义访问

- **空属性访问**——在 `null` 或 `undefined` 上访问属性，缺少空检查或可选链
- **缺少返回值**——函数返回 `undefined` 而非期望值，缺少 `return` 语句或走了错误分支
- **解构空值**——对 `null`/`undefined` 进行数组/对象解构，API 返回了错误形状而非数据
- **未设置默认值的可选参数**——可选参数使用但无默认值，调用方省略了参数

## 差一/边界

- **错误的循环边界**——循环从 1 开始而非 0，或在 `length` 而非 `length - 1` 处结束
- **栅栏错误**——"N 个元素需要 N-1 个分隔符"计算错误
- **包含与排除**——范围边界 `<` 与 `<=`，切片/子字符串结束索引
- **空集合**——`.length === 0` 落入假定有元素存在的逻辑

## 异步/时序

- **缺少 await**——异步函数调用未使用 `await`，得到 Promise 对象而非解析后的值
- **竞态条件**——两个异步操作在没有协调的情况下读写同一状态
- **过时闭包**——回调捕获了旧变量值，而非当前值
- **初始化顺序**——事件处理器在设置完成前触发
- **泄漏的定时器**——超时/间隔未清理，在组件/上下文销毁后触发

## 状态管理

- **共享突变**——原地修改对象/数组，影响其他消费者
- **过时渲染**——状态更新但 UI 未重新渲染，缺少响应式触发或引用错误
- **过时处理器状态**——闭包在绑定时捕获状态，而非当前值
- **双数据源**——相同数据存储在两个地方，其中一个不同步
- **无效转换**——状态机允许缺少守卫条件的转换

## 导入/模块

- **循环依赖**——模块 A 导入 B，B 导入 A，其中一个得到 `undefined`
- **导出不匹配**——默认导出与命名导出，`import X` 与 `import { X }`
- **错误的扩展名**——`.js` 与 `.cjs` 与 `.mjs`，`.ts` 与 `.tsx`
- **路径大小写敏感**——在 Windows/macOS 上工作，在 Linux 上失败
- **缺少扩展名**——ESM 要求在 import 中使用显式文件扩展名

## 类型/强制转换

- **字符串与数字比较**——`"5" > "10"` 为 `true`（字典序），`5 > 10` 为 `false`
- **隐式强制转换**——`==` 而非 `===`，truthy/falsy 意外（`0`、`""`、`[]`）
- **数值精度**——`0.1 + 0.2 !== 0.3`，大整数精度丢失
- **有效但 falsy 的值**——值为 `0` 或 `""`，有效但为 falsy

## 环境/配置

- **缺少环境变量**——环境变量缺失或 dev 与 prod 与 CI 中的值错误
- **硬编码路径**——在一台机器上工作，在另一台上失败
- **端口冲突**——端口已被占用，先前的进程仍在运行
- **权限拒绝**——部署中不同用户/组
- **缺少依赖**——不在 package.json 中或未安装

## 数据形状/API 合约

- **响应形状变更**——后端更新，前端期望旧格式
- **错误的容器类型**——期望数组但得到对象，或反之，`data` 与 `data.results` 与 `data[0]`
- **缺少必需字段**——payload 中省略了必需字段，后端返回验证错误
- **日期格式不匹配**——ISO 字符串与时间戳与本地化字符串
- **编码不匹配**——UTF-8 与 Latin-1、URL 编码、HTML 实体

## 正则/字符串

- **粘性 lastIndex**——正则 `g` 标志先在 `.test()` 后用在 `.exec()`，`lastIndex` 在调用间未重置
- **缺少转义**——`.` 匹配任何字符，`$` 是特殊字符，反斜杠需要双写
- **贪婪过度匹配**——`.*` 吞噬分隔符，需要使用 `.*?`
- **错误的引号类型**——字符串插值需要反引号模板字面量

## 错误处理

- **错误被吞没**——空的 `catch {}` 或仅记录但不重新抛出/处理
- **错误的错误类型**——捕获基础 `Error` 而需要特定类型
- **处理器中的错误**——清理代码抛出异常，掩盖原始错误
- **未处理的拒绝**——在 `await` 周围缺少 `.catch()` 或 try/catch

## 作用域/闭包

- **变量遮蔽**——内部作用域声明了同名变量，隐藏了外部变量
- **循环变量捕获**——所有闭包共享相同的 `var i`，使用 `let` 或 bind
- **丢失 this 绑定**——回调丢失上下文，需要 `.bind()` 或箭头函数
- **作用域混淆**——`var` 提升到函数级别，`let`/`const` 是块作用域

</patterns>

<usage>

## 如何使用此清单

1. **在形成任何假设之前**，根据症状扫描相关类别
2. **将症状匹配到模式**——如果 bug 涉及"undefined is not an object"，首先检查空/未定义
3. **每个匹配的模式都是一个假设候选**——用证据验证或排除
4. **如果没有模式匹配**，继续进行开放式调查

### 症状到类别的快速映射

| 症状 | 首先检查 |
|---------|------------|
| "Cannot read property of undefined/null" | 空/未定义访问 |
| "X is not a function" | 导入/模块、类型/强制转换 |
| 有时工作，有时失败 | 异步/时序、状态管理 |
| 本地工作，CI/生产环境失败 | 环境/配置 |
| 显示错误的数据 | 数据形状、状态管理 |
| 少一项/缺少最后一项 | 差一/边界 |
| "Unexpected token" / 解析错误 | 数据形状、类型/强制转换 |
| 内存泄漏 / 资源使用增长 | 异步/时序（清理）、作用域/闭包 |
| 无限循环 / 调用栈溢出 | 状态管理、异步/时序 |

</usage>
