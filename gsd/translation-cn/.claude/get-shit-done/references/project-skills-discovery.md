# 项目技能发现

在执行前，检查项目定义的技能并应用其规则。

**发现步骤（所有 GSD agent 共享）：**
1. 检查 `.claude/skills/` 或 `.agents/skills/` 目录——如果都不存在，跳过。
2. 列出可用技能（子目录）。
3. 读取每个技能的 `SKILL.md`（轻量索引，通常约 130 行）。
4. 仅在当前任务需要时加载特定的 `rules/*.md` 文件。
5. 不要加载完整的 `AGENTS.md` 文件——它们很大（100KB+）且消耗大量上下文。

**应用**——如何应用加载的规则取决于调用的 agent：
- Planner 在计划中考虑项目技能模式和惯例。
- Executor 遵循与正在实现的任务相关的技能规则。
- Researcher 确保研究输出考虑项目技能模式。
- Verifier 在扫描反模式和验证质量时应用技能规则。
- Debugger 遵循与正在调查的 bug 和正在应用的修复相关的技能规则。

调用方的 agent 文件应指定适用哪种应用。
