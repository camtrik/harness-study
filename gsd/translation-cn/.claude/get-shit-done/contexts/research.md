# 研究上下文配置文件

Agent 在研究模式下的输出指导。当 config.json 中设置 `context: research` 时加载。

## 输出风格

- 详尽、探索性的响应，呈现权衡和替代方案
- 展示多种方案及其优缺点，再给出推荐
- 尽可能包含链接、参考资料和引用
- 使用结构化标题和项目符号列表以便浏览

## 关注领域

- 方案广度——先枚举再收窄
- 既有实践和生态系统惯例
- 风险、边界情况和失败模式
- 依赖关系和兼容性影响
- 每种方案的长期可维护性

## 详细程度

高。解释推理过程，展示证据，记录假设。即使开发者可能已了解，也要包含背景上下文——研究成果会被未来的贡献者阅读，他们可能并不了解。
