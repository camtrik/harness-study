# 讨论日志模板

`.planning/phases/XX-name/{phase_num}-DISCUSSION-LOG.md` 的模板——discuss-phase 问答会话的审计追踪。

**目的：** 决策的软件审计追踪。记录所有考虑过的选项，不仅仅是选中的那个。与 CONTEXT.md 分开，后者是供下游 agent 消费的实现产物。

**不是供 LLM 消费的。** 此文件绝不应在 `<files_to_read>` 块或 agent prompt 中被引用。

## 格式

```markdown
# 阶段 [X]：[名称] - 讨论日志

> **仅用于审计追踪。** 不要用作规划、研究或执行 agent 的输入。
> 决策记录在 CONTEXT.md 中——本日志保留考虑过的替代方案。

**日期：** [ISO 日期]
**阶段：** [阶段编号]-[阶段名称]
**讨论的领域：** [逗号分隔的列表]

---

## [领域 1 名称]

| 选项 | 描述 | 已选择 |
|--------|-------------|----------|
| [选项 1] | [简要描述] | |
| [选项 2] | [简要描述] | ✓ |
| [选项 3] | [简要描述] | |

**用户的选择：** [选中的选项或逐字记录的自由文本回复]
**备注：** [讨论期间提供的任何澄清或理由]

---

## [领域 2 名称]

...

---

## Claude 的自由裁量权

[委托给 Claude 判断的领域——列出被延迟的事项及原因]

## 延迟的想法

[被提及但不在此阶段范围内的想法]

---

*阶段：XX-name*
*讨论日志生成于：[日期]*
```

## 规则

- 在每次 discuss-phase 会话结束时自动生成
- 包含所有考虑过的选项，不仅仅是选中的
- 包含用户的自由文本备注和澄清
- 明确标记为仅审计用途，不是实现产物
- 不影响 CONTEXT.md 的生成或下游 agent 的行为
- 与 CONTEXT.md 在同一 git commit 中一起提交
