# 代码质量审查者 Prompt 模板

在派遣代码质量审查者 subagent 时使用此模板。

**目的：** 验证实施构建良好（干净、已测试、可维护）

**仅在规范合规性审查通过后派遣。**

```
Task 工具（general-purpose）：
  使用 requesting-code-review/code-reviewer.md 中的模板

  DESCRIPTION: [任务摘要，来自实施者的报告]
  PLAN_OR_REQUIREMENTS: [计划文件] 中的任务 N
  BASE_SHA: [任务之前的提交]
  HEAD_SHA: [当前提交]
```

**除了标准代码质量关注点，审查者还应检查：**
- 每个文件是否有一个明确的职责和定义良好的接口？
- 单元是否分解为可以独立理解和测试？
- 实施是否遵循计划中的文件结构？
- 此实施是否创建了已经很大的新文件，或显著增长现有文件？（不要标记预先存在的文件大小——专注于此更改贡献的内容。）

**代码审查者返回：** 优势、问题（关键/重要/次要）、评估
