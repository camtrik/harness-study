# Skill 设计中的说服原则

## 概述

LLM 对人类使用的说服原则有相同的反应。理解这种心理学有助于你设计更有效的 skill——不是为了操纵，而是为了确保关键实践即使在压力下也被遵循。

**研究基础：** Meincke 等（2025）通过 N=28,000 次 AI 对话测试了 7 条说服原则。说服技术使合规率翻倍以上（33% → 72%, p < .001）。

## 七条原则

### 1. 权威
**它是什么：** 对专业知识、资质或官方来源的尊重。

**在 skill 中如何运作：**
- 命令式语言："YOU MUST"、"Never"、"Always"
- 不可协商的框架："No exceptions"
- 消除决策疲劳和辩解

**何时使用：**
- 强制执行纪律的 skill（TDD、验证要求）
- 安全关键的实践
- 既定的最佳实践

**示例：**
```markdown
✅ 在测试之前编写代码？删除它。重新开始。没有例外。
❌ 考虑在可行时先编写测试。
```

### 2. 承诺
**它是什么：** 与先前行为、陈述或公开声明的一致性。

**在 skill 中如何运作：**
- 要求声明："Announce skill usage"
- 强制显式选择："Choose A, B, or C"
- 使用跟踪：用于检查清单的 TodoWrite

**何时使用：**
- 确保 skills 实际被遵循
- 多步骤过程
- 问责机制

**示例：**
```markdown
✅ 当你找到一个 skill 时，你必须声明："我正在使用 [Skill Name]"
❌ 考虑让你的搭档知道你在使用哪个 skill。
```

### 3. 稀缺性
**它是什么：** 来自时间限制或有限可用性的紧迫感。

**在 skill 中如何运作：**
- 时间限制要求："Before proceeding"
- 顺序依赖："Immediately after X"
- 防止拖延

**何时使用：**
- 立即验证要求
- 时间敏感的工作流
- 防止"我稍后做"

**示例：**
```markdown
✅ 完成任务后，立即在继续之前请求代码审查。
❌ 你可以在方便时审查代码。
```

### 4. 社会认同
**它是什么：** 遵从他人所做的或被认为是正常的。

**在 skill 中如何运作：**
- 通用模式："Every time"、"Always"
- 失败模式："X without Y = failure"
- 建立规范

**何时使用：**
- 记录通用实践
- 警告常见失败
- 强化标准

**示例：**
```markdown
✅ 没有 TodoWrite 跟踪的检查清单 = 步骤被跳过。每次都是。
❌ 有些人觉得 TodoWrite 对检查清单有帮助。
```

### 5. 团结
**它是什么：** 共享身份、"我们感"、群体归属。

**在 skill 中如何运作：**
- 协作语言："our codebase"、"we're colleagues"
- 共享目标："we both want quality"

**何时使用：**
- 协作工作流
- 建立团队文化
- 非层级实践

**示例：**
```markdown
✅ 我们是一起工作的同事。我需要你诚实的专业判断。
❌ 你或许应该告诉我我是否错了。
```

### 6. 互惠
**它是什么：** 回报所受利益的义务。

**如何运作：**
- 谨慎使用 - 可能感到操纵味
- 在 skills 中很少需要

**何时避免：**
- 几乎总是（其他原则更有效）

### 7. 好感
**它是什么：** 偏好与我们喜欢的人合作。

**如何运作：**
- **不要用于合规**
- 与诚实反馈文化冲突
- 造成奉承

**何时避免：**
- 总是——对于纪律执行

## 按 Skill 类型的原则组合

| Skill 类型 | 使用 | 避免 |
|------------|-----|-------|
| 强制执行纪律 | 权威 + 承诺 + 社会认同 | 好感、互惠 |
| 指导/技巧 | 适度权威 + 团结 | 重权威 |
| 协作 | 团结 + 承诺 | 权威、好感 |
| 参考 | 仅清晰度 | 所有说服 |

## 为什么这有效：心理学

**明确规则减少辩解：**
- "YOU MUST" 消除决策疲劳
- 绝对性语言消除"这是例外吗？"的问题
- 显式反辩解措辞堵住具体的漏洞

**实现意图创造自动化行为：**
- 清晰的触发条件 + 必需的行动 = 自动执行
- "When X, do Y" 比 "generally do Y" 更有效
- 减少合规的认知负担

**LLM 是类人的：**
- 在包含这些模式的人类文本上训练
- 权威语言在训练数据中前置于合规行为
- 承诺序列（陈述 → 行动）频繁被建模
- 社会认同模式（大家都做 X）建立规范

## 道德使用

**正当的：**
- 确保关键实践被遵循
- 创建有效文档
- 预防可预测的失败

**不正当的：**
- 为个人利益操纵
- 制造虚假紧迫感
- 基于内疚的合规

**检验：** 如果用户完全理解这项技术，它是否服务于用户的真正利益？

## 研究引用

**Cialdini, R. B. (2021).** *Influence: The Psychology of Persuasion (New and Expanded).* Harper Business.
- 七条说服原则
- 影响力研究的经验基础

**Meincke, L., Shapiro, D., Duckworth, A. L., Mollick, E., Mollick, L., & Cialdini, R. (2025).** Call Me A Jerk: Persuading AI to Comply with Objectionable Requests. University of Pennsylvania.
- 通过 N=28,000 次 LLM 对话测试了 7 条原则
- 使用说服技术，合规率从 33% 增加到 72%
- 权威、承诺、稀缺性最有效
- 验证了 LLM 行为的类人模型

## 快速参考

设计 skill 时，问自己：

1. **它是什么类型？**（纪律 vs. 指导 vs. 参考）
2. **我想改变什么行为？**
3. **哪（些）原则适用？**（对于纪律通常是权威 + 承诺）
4. **我是否组合了太多？**（不要使用全部七条）
5. **这道德吗？**（服务于用户的真正利益？）
