# Skill 设计的说服原则

## 概述

LLM 对与人类相同的说服原则做出响应。理解这种心理学有助于你设计更有效的 skills——不是为了操纵，而是为了确保即使在压力下也能遵循关键实践。

**研究基础**：Meincke 等人（2025）测试了 7 个说服原则，涉及 N=28,000 次 AI 对话。说服技术使合规率翻了一番（33% → 72%，p < .001）。

## 七个原则

### 1. 权威
**它是什么**：对专业知识、凭证或官方来源的尊重。

**它在 skills 中如何工作**：
- 强制性语言："你必须"、"绝不"、"始终"
- 不可协商的框架："没有例外"
- 消除决策疲劳和合理化

**何时使用**：
- 执行纪律的 skills（TDD、验证要求）
- 安全关键实践
- 既定的最佳实践

**示例**：
```markdown
推荐 在测试之前编写代码？删除它。重新开始。没有例外。
不推荐 考虑在可行时首先编写测试。
```

### 2. 承诺
**它是什么**：与先前的行动、声明或公开声明的一致性。

**它在 skills 中如何工作**：
- 需要公告："宣布 skill 使用"
- 强制明确选择："选择 A、B 或 C"
- 使用跟踪：TodoWrite 用于检查表

**何时使用**：
- 确保 skills 实际上被遵循
- 多步骤流程
- 问责机制

**示例**：
```markdown
推荐 当你找到一个 skill 时，你必须宣布："我正在使用 [Skill Name]"
不推荐 考虑让你的搭档知道你正在使用哪个 skill。
```

### 3. 稀缺性
**它是什么**：来自时间限制或有限可用性的紧迫感。

**它在 skills 中如何工作**：
- 时间限制要求："在继续之前"
- 顺序依赖："紧接在 X 之后"
- 防止拖延

**何时使用**：
- 立即验证要求
- 时间敏感的工作流
- 防止"我稍后再做"

**示例**：
```markdown
推荐 完成任务后，立即在继续之前请求代码审查。
不推荐 你可以在方便时审查代码。
```

### 4. 社会证明
**它是什么**：对其他人所做或被认为正常的事情的遵守。

**它在 skills 中如何工作**：
- 普遍模式："每次"、"始终"
- 失败模式："X 没有 Y = 失败"
- 建立规范

**何时使用**：
- 记录普遍实践
- 警告常见失败
- 加强标准

**示例**：
```markdown
推荐 没有 TodoWrite 跟踪的检查表 = 步骤被跳过。每次都是。
不推荐 有些人发现 TodoWrite 对检查表有帮助。
```

### 5. 统一
**它是什么**：共享的身份、"我们"、群体归属感。

**它在 skills 中如何工作**：
- 协作语言："我们的代码库"、"我们是同事"
- 共享目标："我们都想要质量"

**何时使用**：
- 协作工作流
- 建立团队文化
- 非等级实践

**示例**：
```markdown
推荐 我们是一起工作的同事。我需要你诚实的技术判断。
不推荐 你应该告诉我如果我错了。
```

### 6. 互惠
**它是什么**：回报所获得利益的义务。

**它如何工作**：
- 谨慎使用——可能感觉操纵性
- 在 skills 中很少需要

**何时避免**：
- 几乎总是（其他原则更有效）

### 7. 好感
**它是什么**：倾向于与我们喜欢的人合作。

**它如何工作**：
- **不要用于合规**
- 与诚实反馈文化冲突
- 创造谄媚

**何时避免**：
- 始终用于纪律执行

## 按 Skill 类型的原则组合

| Skill 类型 | 使用 | 避免 |
|------------|-----|-------|
| 执行纪律 | 权威 + 承诺 + 社会证明 | 好感、互惠 |
| 指导/技术 | 适度权威 + 统一 | 重度权威 |
| 协作 | 统一 + 承诺 | 权威、好感 |
| 参考 | 仅清晰 | 所有人说服 |

## 为什么有效：心理学

**明线规则减少合理化**：
- "你必须"消除决策疲劳
- 绝对语言消除"这是一个例外吗？"的问题
- 明确的反合理化计数器关闭特定漏洞

**实施意图创造自动行为**：
- 清晰的触发器 + 所需操作 = 自动执行
- "当 X 时，做 Y"比"一般做 Y"更有效
- 减少合规性的认知负荷

**LLM 是类人的**：
- 在包含这些模式的人类文本上训练
- 权威语言在训练数据中先于合规
- 承诺序列（声明 → 行动）经常被建模
- 社会证明模式（每个人都做 X）建立规范

## 道德使用

**合法**：
- 确保遵循关键实践
- 创建有效的文档
- 防止可预测的失败

**非法**：
- 为了个人利益而操纵
- 制造虚假的紧迫感
- 基于内疚的合规

**测试**：如果用户完全理解此技术，它会服务于用户的真正利益吗？

## 研究引用

**Cialdini, R. B. (2021).** *Influence: The Psychology of Persuasion (New and Expanded).* Harper Business.
- 说服的七个原则
- 影响研究的实证基础

**Meincke, L., Shapiro, D., Duckworth, A. L., Mollick, E., Mollick, L., & Cialdini, R. (2025).** Call Me A Jerk: Persuading AI to Comply with Objectionable Requests. University of Pennsylvania.
- 在 N=28,000 次 LLM 对话中测试了 7 个原则
- 使用说服技术合规率从 33% → 72%
- 权威、承诺、稀缺性最有效
- 验证 LLM 行为的类人模型

## 快速参考

设计 skill 时，请问：

1. **它是什么类型？**（纪律 vs. 指导 vs. 参考）
2. **我试图改变什么行为？**
3. **哪些原则适用？**（通常权威 + 承诺用于纪律）
4. **我组合了太多吗？**（不要使用全部七个）
5. **这是道德的吗？**（服务于用户的真正利益？）
